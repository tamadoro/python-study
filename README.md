# Target Game

画面を移動するアイコンをクリックして得点を競うゲームです。ブラウザー版とPygame版があります。

## Pygame版に必要な環境

- Python 3
- Pygame

Pygameがインストールされていない場合は、次のコマンドでインストールしてください。

```bash
python -m pip install pygame
```

## 起動方法

### ブラウザー版

リポジトリのルートディレクトリで簡易Webサーバーを起動し、ブラウザーで `http://localhost:8000/` を開きます。

```bash
python -m http.server 8000
```

`index.html` と `icon/` フォルダーを同じ配置のまま公開すれば、静的Webサイトとしても遊べます。
ブラウザー版はJavaScriptで動作するためPygameは不要です。静的Webサイトとして公開する場合、Pythonも必要ありません。

### Pygame版

リポジトリのルートディレクトリで、次のコマンドを実行します。

```bash
python game.py
```

## 遊び方

1. 開始画面で難易度を選びます。
2. 30秒以内に、スコープを移動アイコンに重ねてクリックします。
3. アイコンによって得点が異なります。クリックしたアイコンは画面から消え、得点とアイコン別のクリック数が更新されます。
4. 障害物と重なっている移動アイコンは一時的に見えなくなり、クリックできません。
5. 30秒経過、またはプレイ中にEscキーを押すと結果画面に移ります。結果画面には得点とアイコン別のクリック数が表示されます。
6. 結果画面で難易度を選ぶと、その難易度で再スタートします。

### 難易度

| 難易度 | 障害物の数 |
| --- | ---: |
| easy | 3 |
| normal | 4 |
| hard | 5 |
| veryhard（鬼hard） | 10 |
